# 🌟 Personal Portfolio Website

This repository contains a personal portfolio website showcasing **projects**, **skills**, **resume**, and **GitHub contributions**. It’s designed to give visitors a quick overview of who I am, what I’ve built, and how to connect with me.

## 🔗 Live Link

> [GitHub Profile & Portfolio](https://github.com/Pavithira-10/FUTURE_FS_01)

## 📄 Pages

- `index.html` – Home or landing page of the portfolio.
- `resume portfolio.html` – Online resume section highlighting education, experience, and skills.
- `projects/` – (Optional) Add your project showcases here.

## ✨ Features

- Clean layout with navigation
- GitHub-linked contributions and account integration
- Responsive design elements
- Resume embedded and styled

## 🛠️ Tech Stack

- HTML5
- CSS3
- GitHub Pages (for hosting)
- Responsive layout practices

## 🚀 How to Use

1. Clone this repo:
   ```bash
   git clone https://github.com/Pavithira-10/FUTURE_FS_01.git
   ```
2. Open `index.html` in your browser to view the portfolio.
3. Customize content, projects, and resume to suit your profile.

## 📌 Notes

- This is designed for quick online showcase of personal branding and work.
